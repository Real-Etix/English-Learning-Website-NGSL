## Definition
An uncertainty, possibility, condition, doubt etc.

## Examples
- If it rains, I shall get wet. _(dictionaryapi)_
- If A, then B, else C. _(dictionaryapi)_
- I would be unhappy if you had not talked with me yesterday. _(dictionaryapi)_
